## おぼえて書く（2026-09-22・iPad Safari実機確認済み）

ひらがな・漢字コースの書く画面で「🚩 おぼえて書く」を選びます。どちらのコースも開始時は従来どおり「🚂 なぞり書き」です。まず3秒間見本を表示し、3・2・1の後、十字の点線マスと次の画の始点だけが残ります。漢字では上部の字を隠して読みだけにします。ひらがなではその文字を案内として表示します。画面には指で書いた筆跡が残り、最後の画を離すと正解の線を重ねて「大開通！」と表示します。

- 「💡 ヒント」は1秒だけ薄く見本を表示。補助を使っても5問後のカードや既存のキラ条件は同じです。5問目の強制チャレンジは設けません。
- 書いている途中でも「🚂 なぞり書き」に戻れます。確定済みの画は保持し、切り替えを伴う問題は補助ありとして記録します。完了画面では次の問題へ進んでから切り替えます。
- 自力モード専用の判定は、始点から14座標以内のずれ、概ね0.8〜1.2倍の大きさ、最大12度の傾きを候補として検証します（109座標の字形）。画の途中は10座標の揺れを許し、折り返しや同線の遡りでは複数の通過位置を順序付きで追います。方向・曲がる経路・別画を確認し、曖昧な場合は無理に正誤を決めません。近接した画は位置で区別するため、この範囲のすべての変形が必ず通るという意味ではありません。通常のなぞり判定は従来どおりです。
- 中断後は3秒の見本から再開し、確定した画と筆跡を復元します。現在の1文字だけ、1画128点以下の筆跡を端末内の保存・バックアップに含め、次の問題で削除します。長期履歴には筆跡を残しません。古い保存・バックアップは通常モードとして読み込めます。
- 親向け履歴の各問題に「おぼえて書く（切替を含む）」を表示。始点がある練習であり、紙上での完全自力の定着を判定する機能ではありません。

**自動検証**：既存のデータ整合性・コア・ブラウザに加え、自力モードの判定・保存とブラウザ操作を検証。漢字22字・68画とひらがな35字・85画の正順、位置ずれ、傾き、大きさ、逆方向、曲線・折れ線のショートカット拒否、3秒表示、1秒ヒント、筆跡・中断復帰、タッチキャンセル、5問後の報酬、モード切替、4画面サイズを対象とします。ひらがなでは初期モード、表示・切替、筆跡保存に加え、全35字の疎な入力・小さな揺れ・短い遡りを含む疑似筆跡を確認します。「ね」「れ」は現行コースに未収録のため、同線を折り返す模式経路で正順・逆走・近道の判別を検証します。

**iPad Safari実機確認**：漢字の想起モードは家庭内サーバーの版で書き心地と操作を確認し、ユーザーから「実機確認OK」の報告を受けました。ひらがなの想起モードでは「わ」「ゆ」などを正しく書いても不合格になるとの実機報告を受け、判定をローカル修正しました。修正後のiPad Safari実機確認と公開URLの確認は別途必要です。

## 今回の試し方

1. ホームで「👦 さっくん」または「👧 かなちゃん」を選びます。さっくんは「ひらがな／かんじ」を選択でき、中断中は「▶️ つづきから／🆕 はじめから」が表示されます。かなちゃんは「あそぶ」1つだけで、ひらがなを新規開始し、中断中なら自動的に続きから再開します。
2. 必要なら「ヒント」「おてほん」。補助を使っても報酬は同じです。
3. 5問で電車カード1枚。「ずかん」で写真と豆知識を見られます。
4. 親は「おうちの方へ → 書き順の記録」で、どの画を選んだかを確認できます。
5. 「おやすみ」で中断。確定した画まで保存し、後から続けられます。
6. 40枚コンプリート済みのプロフィールで5問を正しい書き順で終えると、キラ未獲得のカードが★2になります。線から脱線して書き直しても対象です。「ずかん」でキラ枚数と金枠を確認できます。別の画や逆走を選んだ5問セットではキラ化しません。

ひらがなの最初の5問：や・ふ・せ・ほ・も。次は、や・む・せ・よ・い。漢字の最初の5問：一・二・三・四・五。以後は、ひらがなと漢字がそれぞれ独立した順番で巡回します。重点文字と指定出題は親向け設定で変更でき、選んだコース内の次の5問から反映されます。
