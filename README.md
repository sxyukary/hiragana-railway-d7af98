# もじ鉄図鑑

作成：2026-09-19。設計書v2の段階A・Bを実装。旧版は変更していません。GitHub Pages公開後、アプリ名を「もじ鉄図鑑」に変更し、専用アイコンと図鑑だけのリセット機能を追加。さらに、ひらがな／かんじのコース選択、漢字17字（一〜十・山・川・木・目・月・上・下）、基本の読み表示を追加しました。2026-09-19、図鑑を8枚から20枚へ拡張し、Kizashiは家族撮影の実写をAI補正せず収録しました。2026-09-20、娘向けの簡単なひらがな15字を追加してひらがなを全22字へ拡張し、貨物列車5両を加えて図鑑を全25枚にしました。

**公開URL：<https://sxyukary.github.io/hiragana-railway-d7af98/>**

## 開く

**[iPadのSafariで試す](http://192.168.3.5:8228/railway/)**

今回の確認用URLはMacと同じWi-Fiで使います。Macは起動したままにしてください。前の試作とはポート・URLが異なります。停止した場合は、このフォルダの `iPadで試す.command` をMacで開くと、その時点のアドレスが表示されます。停止はControl+Cです。

インターネット公開ではありません。Mac不要で使う工程は後述のGitHub Pages公開です。サイトデータを消すとカードや書き順記録も消えるため、公開先へ移す前に「おうちの方へ → 記録のバックアップと復元」で書き出してください。異なるポート・公開URLの間では自動で記録を引き継ぎません。

## 今回の試し方

1. ホームで「👦 さっくん」または「👧 かなちゃん」を選びます。さっくんは「ひらがな／かんじ」を選択でき、中断中は「▶️ つづきから／🆕 はじめから」が表示されます。かなちゃんは「あそぶ」1つだけで、ひらがなを新規開始し、中断中なら自動的に続きから再開します。
2. 必要なら「ヒント」「おてほん」。補助を使っても報酬は同じです。
3. 5問で電車カード1枚。「ずかん」で写真と豆知識を見られます。
4. 親は「おうちの方へ → 書き順の記録」で、どの画を選んだかを確認できます。
5. 「おやすみ」で中断。確定した画まで保存し、後から続けられます。

ひらがなの最初の5問：や・ふ・せ・ほ・も。次は、や・む・せ・よ・い。漢字の最初の5問：一・二・三・四・五。以後は、ひらがなと漢字がそれぞれ独立した順番で巡回します。重点文字と指定出題は親向け設定で変更でき、選んだコース内の次の5問から反映されます。

## 実装した範囲

- ひらがな22字（や・せ・ふ・ほ・も・む・よ・い・つ・し・く・へ・り・こ・う・て・と・に・か・た・な・の）と漢字17字（一〜十・山・川・木・目・月・上・下）。案内なしが標準。追加15字は、簡単な字から「い・つ・し・く・へ」「り・こ・う・て・と」「に・か・た・な・の」の順で登録。
- 漢字を書く画面では、読み始めに合わせた基本の読みを常時表示。一〜十は「いち・に・さん・よん・ご・ろく・なな・はち・きゅう・じゅう」、そのほかは「やま・かわ・き・め・つき・うえ・した」。複数の音読み・訓読みはこの段階では併記しない。
- 新しい5問を始めるときに「ひらがな／かんじ」を選択。途中の5問は同じコースのまま再開し、獲得画面の「もういちど」も直前のコースを継続。
- 「👦 さっくん」と「👧 かなちゃん」で、図鑑カード、学習記録、設定、中断セーブを別々に保存。保存キーは `mojitetsu_sakkun_state_v2` と `mojitetsu_kanachan_state_v2`。選択中のユーザーは `mojitetsu_active_profile` に保存。
- さっくんはひらがな・漢字の2コース。かなちゃんはひらがな専用で、「あそぶ」から直接開始。途中データがある場合もボタンを増やさず自動再開する。かなちゃんの親向け画面では、漢字の記録と設定を表示しない。
- 旧キー `hiragana-railway-v2` の記録が残っている場合は、初回にさっくんの保存先へコピー。旧キー自体は削除しない。
- 中断データがあるときは「つづきから」と「はじめから」を選択。「はじめから」はその未完了セッションだけを破棄し、過去の完了記録・カード・設定は残す。
- ひらがなと漢字の巡回位置は独立。以前の保存データはそのまま読み込み、初めて選ぶ漢字コースは一〜五から開始。
- 1回5問。最初はRed Wing、以後は未獲得カードから均等に抽選。全25種類獲得後は「きょうの1枚」として再表示し、図鑑の枚数を増やしません。
- カード：既存8枚（227系0番台 Red Wing、500系、N700系8000番台、800系、883系ソニック、885系、787系、700系レールスター）に、923形ドクターイエロー、227系Kizashi、227系Urara、N700S、E5系、E6系、W7系、285系サンライズ、273系やくも、117系WEST EXPRESS銀河、87系TWILIGHT EXPRESS瑞風、ななつ星in九州、JR貨物EF210形（桃太郎）、EH500形（金太郎）、EH200形（ブルーサンダー）、EF510形（レッドサンダー）、EF66形（ニーナ）を追加した全25枚。
- アプリ名は、ひらがな・カタカナ・漢字へ広げられる「もじ鉄図鑑」。架空の電車・練習帳・鉛筆を組み合わせた専用アイコンとWebアプリマニフェストを収録。
- 大人向け画面から、図鑑のカードだけを0枚に戻せます。実行前に確認画面を表示し、書き順記録・重点文字・出題設定・途中の練習は残します。
- 写真はすべて実物。作者・ライセンス・豆知識の根拠を [出典一覧](sources.html) に収録。
- ゲーム本体と出典一覧に `noindex, nofollow, noarchive, noimageindex` を指定。検索結果・検索キャッシュ・画像検索への掲載を抑制します。ただし、アクセス制限や秘密保持ではなく、URLを知る人は閲覧できます。
- 出典一覧には写真の原題、作者、原典、ライセンス、変更内容を明記し、非公式・無関係の表示と第三者の名称・ロゴに関する権利表示を追加。
- 書く画面は可視領域内に固定。背景スクロールを止め、入力領域のタッチ移動を受け取ります。図鑑では通常のスクロールができます。
- ホーム・書く画面・カード・図鑑は子ども用画面として、ダブルタップやピンチによる拡大、写真のドラッグ、横方向のジェスチャー、選択操作を抑止。図鑑の縦スクロールは維持し、「おうちの方へ」画面では通常の拡大・選択操作を残します。
- 親向け記録は、自力での完了、補助後の完了、画の取り違え、逆方向、曖昧な入力・中断を区別。全軌跡や個人名は保存しません。
- 最初の判定可能な画の選択を記録し、同じ画の再試行を間違い回数として水増ししません。1問内で補助を使った後は補助後の選択として記録します。
- 直近100セッション、最大500問の履歴。古い履歴を外してもカードは残します。
- ユーザー別の中断復帰、JSONファイルとテキスト文字列のバックアップ・復元、破損・未対応バージョンの拒否、保存失敗の表示、別タブ更新時の一時停止。バックアップは現在選択中の1人分だけを対象とし、対象名を画面・ファイル名・データ内に記録。従来のバックアップ形式も復元可能。
- 親向け画面の「🔄 アプリを最新に更新」から、保存データを消さずに日時付きURLで最新の入口を取得。CSS・JavaScript・マニフェスト・アイコンには共通バージョン `20260920_3` を付け、次の公開時はこの番号を更新して古いキャッシュと分離します。
- コード・文字・車両データを分離。将来の文字やカード追加で判定エンジン全体を書き換える必要はありません。

## 検証したこと

2026-09-19〜20、Mac上の独立したChromeテスト環境で確認。実機Safariの代用とはしません。

- ひらがな22字すべての全画を正順で入力。追加15字は指定出題による5問セット3回で全字が巡回することを確認。
- 漢字17字すべての全画を正順で入力し、5問セット4回で全字が巡回することを確認。漢字コースが一〜五から始まり、「もういちど」で漢字を継続することも確認。
- 漢字17字すべてで、指定した読みが画面に表示され、書字領域の読み上げ用ラベルにも含まれることを確認。
- 既存のひらがなを遊んだ後でも、漢字の巡回位置に影響せず一から始まることを確認。漢字用の巡回位置を持たない従来の保存データもそのまま読み込めることを確認。
- 「や」「せ」の2画目に3画目を選ぶと進まない。親向け記録に期待2画目→選択3画目が残る。
- 補助前の取り違えと、その後の補助あり成功を分離。
- 線から少しずれた入力・疎な入力イベント・輪のある文字の正順が通る。
- 曲線の始点から終点へ直線で飛ぶ操作を拒否。逆方向・タップは完了にしない。
- 2026-09-19の実機フィードバックを受け、書き順・方向の識別は維持したまま、始点と経路の許容幅を文字座標の7から10へ調整。許容範囲内の平行なずれが通り、範囲外の始点・逆方向・曲線の飛び越しは通らないことを自動テストで確認。
- 2026-09-20、正しい始点・方向・経路で終点へ到達した画をロックし、その後の短い「はね・はらい」がガイド線から外れても、指離しで成功にするよう調整。終点前の逸脱、逆方向、別画、タップ、曲線の飛び越し、タッチキャンセルは引き続き拒否することを自動テストで確認し、iPad Safari実機でも「はね・はらい」の書き心地を確認。
- 指離しまで画を確定しない。Touchイベントの入力とcancelを検証。
- 一部の画を終えて中断・再読込すると、その続きから再開。
- 5問後にカード1枚。再読込でも増えず、2回目は別のカード。
- 図鑑・拡大写真・豆知識・記録一覧・JSONファイルとテキスト文字列のバックアップ／復元・不正データの拒否。
- 全25カードのID・画像参照が重複せず、画像25件と出典25件が読み込めることを確認。従来の8枚を獲得済みの保存データが「8 / 25」としてそのまま継続できることを確認。
- 図鑑リセットの確認・キャンセル・実行・再保存。カードだけが0枚になり、書き順記録と設定が残ることを確認。
- 「もじ鉄図鑑」の表示名、ホーム画面用アイコン、Webアプリマニフェストの読み込み、入口資産の共通バージョン指定を確認。
- 強制更新後も同じオリジンの `localStorage` が残り、獲得済みカードを維持したまま日時付きURLへ移ることを確認。
- 768×1024、1024×768、390×844で書く画面が縦にスクロールしない。文字領域とボタンの表示を画像でも確認。
- 100セッション上限、全カード獲得後の動作、保存失敗時の一時プレイ、破損記録の非上書き、別タブとの競合。
- テスト中のJavaScriptエラーなし。
- 家庭内アドレスでゲームHTTP 200、ゲーム外のファイル・ディレクトリ一覧HTTP 404。
- iPad Safari実機で、調整後のなぞり判定と子ども用画面のジェスチャー抑止をユーザーが最終確認。

文字の順序はKanjiVGのパスと照合。追加15字もKanjiVGの原典SVGから画順どおりに収録しています。「ふ・ほ・む・も・や・よ」は [ちびむすドリルの筆順図3](https://happylilac.net/pdf/s37_hiragana_kakijun_test2025ans-03.pdf)・[筆順図4](https://happylilac.net/pdf/s37_hiragana_kakijun_test2025ans-04.pdf) も目視参照。教材自体はアプリに同梱しません。「ふ」の左側などに書道的なはねのある字形ですが、画順・方向は照合済みです。学校の教科書体と同一の輪郭ではありません。
